## 文件名

统一采用：`论文名__年份__会议或期刊__IF影响因子.pdf`。

- 已确认数值 JIF：写为 `IF数值`。
- 会议、预印本、书籍、报告及独立附件等无适用 JIF：写为 `IF不适用`。
- 刊物在现有 JCR2025、IEEE2026 资料中未确认数值 JIF：写为 `IF暂无`。
- 刊会或影响因子仍无法可靠确认：写为 `IF未确认`，不猜测数值。
- 过长题名会截短并保留 Zotero Key；同名但内容不同的文件仍保留。

影响因子来源与逐项依据见 `PDF目录.csv`、`影响因子依据.json` 和 `校验清单.json`。JIF 是所引资料中的期刊指标，不是论文发表当年的历史指标。
